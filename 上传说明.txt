航旅纵横探索 Demo · GitHub Pages 发布说明

这是完整静态网页，不是 TXT 文本稿，无需安装或编译。

上传方式：
1. 打开 GitHub 仓库，选择 Add file → Upload files。
2. 将此文件夹内的 index.html、style.css、app.js、assets 文件夹一起上传；保持 assets 文件夹结构。
3. index.html 必须直接位于仓库根目录，不要将整个外层文件夹套进去；不要仅上传 ZIP。
4. 点击 Commit changes。
5. 仓库 Settings → Pages → Source 选择 Deploy from a branch，选择 main 分支和 /(root)，保存。
6. 等待 GitHub 显示发布地址，使用该地址分享。

文件说明：
index.html：网页入口
style.css：界面样式
app.js：本地数据及交互
assets/：全部图片与图标
.nojekyll：静态资源发布标记

本 Demo 使用本地模拟航班，不连接真实预订。点击立即预订没有后续动作。
